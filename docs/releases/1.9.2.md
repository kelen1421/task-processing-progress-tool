# ai工作台 1.9.2

- 个性化中的「单击打开任务」和「双击打开任务」改为独立复选框，可同时开启。
- 同时开启时，单击或双击都打开所选的内置或 Codex 聊天；双击只触发一次。最小化仍可从右键菜单操作。
- 只开启单击时保留双击最小化；只开启双击时单击选中。两项都关闭时，单击选中、双击最小化，可右键打开。
- 保留旧版的点击选择、颜色、透明度、固定任务和窗口大小，外观预设不会改变两项勾选状态。
- 更新引导、预览和已完成任务的查看提示，并验证四种点击组合、设置保存及旧版迁移。

下载 `task-processing-progress-1.9.2-macos-universal.zip`，运行「安装或更新.command」覆盖升级；可选个人插件包为 `task-processing-progress-1.9.2-codex-plugin.zip`。公开包采用临时签名，更新后辅助功能授权可能需要重新添加；修复窗口可检查当前版本的实际权限。
