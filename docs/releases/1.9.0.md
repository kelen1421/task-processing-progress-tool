加入轻量内置对话与可调背景透明度，保留原有进度浮窗、固定任务、圆球和覆盖安装。

- 个性化设置可选择内置对话或 Codex 对话；单击、双击只打开所选的一种。
- 内置窗口只显示最近的用户与 AI 消息，默认 10 条，可选 5 或 20 条，完整任务上下文仍由 Codex 保留。
- 支持文本发送、流式回复、停止、复制、草稿保存、审批和问题卡片；正在 Codex 中执行的任务结束后可续聊。
- 内置对话使用本机 Codex CLI（可发现 Codex.app 内的 CLI）和既有登录，不另填 API 密钥；发送按 CLI 配置连接模型服务并使用账户额度。找不到或不兼容时可在 Codex 中继续。
- 自定义颜色新增界面透明度滑块，以及不透明、半透明、透明背景选项；浮窗和圆球背景同步，文字与进度保持清晰。
- 旧版设置无需手动迁移；旧配色缺少透明度时保持不透明，固定任务、窗口大小和点击方式继续保留。

下载 `task-processing-progress-1.9.0-macos-universal.zip`，运行「安装或更新.command」覆盖升级。可选个人插件包 `task-processing-progress-1.9.0-codex-plugin.zip`。内置聊天窗口无需辅助功能权限；最小化外部聊天窗口仍需要权限。关闭聊天窗口后任务继续运行，退出工作台会提示是否停止内置任务。
