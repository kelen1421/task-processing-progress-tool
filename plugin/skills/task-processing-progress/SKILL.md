---

使用本插件自带的 macOS 应用显示任务进度。解析本机 Codex 会话记录，无需 API 密钥或网络服务。

启动：使用本技能目录的相对路径，执行 `zsh ../../scripts/control.command show`。先将该路径解析为实际插件位置，不要依赖固定工作目录。

用户明确要求关闭时执行相同脚本的 `stop`；检查运行状态执行 `status`，诊断会话读取执行 `diagnose`。

浮窗默认为 240×268 的四宫格，每个聊天任务一格。可拖动边缘或底部左右缩放手柄调整大小；任务对话框可拖动边缘、边角调整大小。两个窗口分别记住尺寸，重启后恢复。右上角减号可最小化为圆球，点击圆球展开并恢复原尺寸；圆球模式跨重启保留。圆球中心显示当前任务数（含完成待查看任务），外圈参考进度最高的进行中任务，无进行中任务时显示待查看任务的完成进度。任务完成后绿色高亮，直到点击对应完成方框。拖动圆球可移动，悬停查看参考任务和百分比，右键提供展开与任务入口。左键单击方框打开对应 Codex 聊天；双击方框将 ChatGPT 的当前普通窗口最小化到 Dock，任务方框、固定状态和完成提示继续保留。首次使用需按照插件提示在“系统设置 → 隐私与安全 → 辅助功能”中开启“任务处理进度”；由用户自行授权。多个窗口打开时优先最小化最近聚焦的普通窗口，其次主窗口。单双击互斥识别，单击会等待系统双击判定时间；完成方框显示 100%，未固定的任务保留直到点击打开后移除。右键任务方框或“已有任务”列表中的任务，可选择“固定到任务栏”或“取消锁定”；固定任务优先显示并跨重启保留，完成后点击查看只清除高亮，卡片继续保留。未开始的固定任务在进度位置显示“等待中”，开始执行后自动更新进度；异常和中断状态单独显示。右键方框可查看阶段、计划和进度依据。空白方框打开“新建 / 已有任务”对话框：支持任务标题搜索、项目选择与任务内容输入。新建通过官方深链把内容带入 Codex 输入框，用户在 Codex 中发送后开始运行；不自动提交提示。

有计划时，百分比按已完成步骤计算；无计划时，“≈”与“估计”标记准备、实现、验证、收尾阶段位置，不代表实际工作量或剩余时间。

此预编译应用支持 macOS 13 及以上的 Apple 芯片和 Intel Mac。若应用不存在或无法启动，报告具体错误，不重复安装依赖或修改 Codex 数据。
