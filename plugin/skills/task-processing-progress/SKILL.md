name: task-processing-progress
description: 启动、关闭或检查“ai工作台”macOS 浮窗；用户希望在其他应用工作时查看 Codex 正在执行的聊天任务时使用。
---

使用本插件自带的 macOS 应用显示任务进度。解析本机 Codex 会话记录；内置聊天通过本机 Codex CLI 及既有登录执行，无需另填 API 密钥。发送时 CLI 按其配置连接模型服务并使用账户额度。

启动：使用本技能目录的相对路径，执行 `zsh ../../scripts/control.command show`。先将该路径解析为实际插件位置，不要依赖固定工作目录。

用户明确要求关闭时执行相同脚本的 `stop`；检查运行状态执行 `status`，诊断会话读取执行 `diagnose`。

浮窗默认为 240×268 的四宫格，每个聊天任务一格。滚轮上下翻页；满载时，下一页保留空白入口，可新建或进入任务。可拖动边缘或底部左右缩放手柄调整大小；任务对话框可拖动边缘、边角调整大小。两个窗口分别记住尺寸，重启后恢复。右上角减号点击范围已扩大，可旋转聚拢为圆球；拖到屏幕任一边缘并松开也自动收起，调整大小不会触发，系统减少动态效果时省略旋转，点击圆球展开并恢复原尺寸；圆球模式跨重启保留。圆球中心显示当前任务数（含完成待查看任务），外圈参考进度最高的进行中任务，无进行中任务时显示待查看任务的完成进度。任务完成后按完成颜色高亮（默认绿色），直到点击对应完成方框。拖动圆球可移动，悬停查看参考任务和百分比，右键提供展开与任务入口。默认左键单击方框打开内置聊天；双击方框最小化所选聊天窗口，任务方框、固定状态和完成提示继续保留。插件自动检测应用程序目录中的旧名「任务处理进度」及新版「ai工作台」，覆盖安装后启动同一位置，保留个性化设置、固定任务和窗口大小；首次默认 ~/Applications/ai工作台.app。仅最小化外部窗口需要辅助功能权限，未授权时只自动打开一次权限修复窗口；菜单栏“辅助功能权限 / 修复”可重新打开。窗口显示当前运行应用位置并自动检查权限。系统开关已开启但仍未生效时，由用户删除旧同名条目，再添加窗口显示的应用并开启；可点击“重启浮窗”刷新。临时签名升级后可能需重新添加授权，不自动修改系统隐私设置。多个窗口打开时优先最小化最近聚焦的普通窗口，其次主窗口。单双击互斥识别，单击会等待系统双击判定时间；完成方框显示 100%，未固定的任务保留直到点击打开后移除。右键任务方框或“已有任务”列表中的任务，可选择“固定到任务栏”或“取消锁定”；固定任务优先显示并跨重启保留，完成后点击查看清除高亮并改为等待中，卡片继续保留；新一轮执行后重新更新进度。未开始的固定任务在进度位置显示“等待中”，开始执行后自动更新进度；异常和中断状态单独显示。右键方框可查看阶段、计划和进度依据。空白方框打开“新建 / 已有任务”对话框：支持任务标题搜索、项目选择与任务内容输入。新建把内容带入所选的聊天输入框，用户点击发送后开始运行；不自动提交提示。

项目筛选右侧的滑杆按钮打开个性化设置；菜单栏和圆球右键也有入口。支持四宫格/条式列表、条形/圆环/分段进度、自定义进行中/完成/背景颜色与背景透明度（不透明、半透明、透明背景或滑块连续调整），预设经典四格/简洁条式/暮色圆环/清爽浅色。预设不改变用户的点击方式。可切换双击打开模式，单击只选中，双击打开聊天；两种模式均可右键打开、最小化、固定和查看详情。打开位置可选内置对话或 Codex，点击只打开所选的一种；最近消息可选 5、10、20 条（默认 10）。预览即时更新，设置自动保存。恢复默认保留固定任务与窗口大小。个性化旁的圆圈问号开启六步使用指引并在浮窗上描边对应位置；菜单栏和圆球右键也可开启。

有计划时，百分比按已完成步骤计算；无计划时，“≈”与“估计”标记准备、实现、验证、收尾阶段位置，不代表实际工作量或剩余时间。

此预编译应用支持 macOS 13 及以上的 Apple 芯片和 Intel Mac。若应用不存在或无法启动，报告具体错误，不重复安装依赖或修改 Codex 数据。

内置聊天使用 Codex app-server 的私有 stdio 连接，按用户设置仅显示最近的用户与 AI 消息。用户在窗口手动发送后才开始执行，支持流式回复、停止、复制和草稿保存。Codex 中正在执行的同一任务先只读查看，结束后才可续聊。审批与用户问题显示确认卡片，不自动授权；不支持的交互提示在 Codex 中继续。关闭窗口不会停止任务，退出工作台会提示是否停止并退出。断线不自动重发。不要代表用户向其他聊天发送消息或批准请求；本技能只授权浮窗启动、停止及诊断，聊天发送由用户直接操作。
