# ai工作台 1.9.3

- 每个新版本首次启动自动打开辅助功能权限配置，显示当前版本并检测新版的实际授权状态；同一版本再次启动不重复升级配置。
- 个性化设置选择 Codex 对话时，增加「辅助功能权限 / 修复」入口。
- 单击打开与双击打开为独立复选框，可以同时开启；双击只打开一次。未开启双击打开时保留双击最小化，右键始终可最小化。
- 旧版的点击选择、颜色、透明度、固定任务和窗口大小继续保留。

下载 `task-processing-progress-1.9.3-macos-universal.zip`，运行「安装或更新.command」覆盖升级；个人插件包为 `task-processing-progress-1.9.3-codex-plugin.zip`。

公开包使用临时签名。升级后如显示授权尚未生效，按配置窗口提示重新添加当前应用；macOS 的触控 ID 或密码验证由本人在系统窗口中完成，软件不自动清除授权或绕过身份验证。
