# ai工作台 1.9.5

- 修复开启“双击打开”后，已展开的任务窗口被再次打开的问题。现在双击按窗口状态切换：未打开或已最小化时打开，已展开时最小化。
- 单击打开与双击切换仍可同时勾选；只开启单击时，双击仍只负责最小化。
- 内置聊天按被点击的任务最小化，避免误缩小最后打开的其他任务；新建任务分配正式 ID 后复用原窗口。
- 外部聊天记录从工作台打开的窗口，优先操作对应窗口；权限不足时显示修复入口，不反复发送打开请求。
- 保留个性化、固定任务、窗口尺寸，以及升级后移除旧辅助授权、重新申请新版授权的流程。
