ai工作台 1.9.6

一、直接使用浮窗
1. 需要 macOS 13 或更高版本，支持 Apple 芯片和 Intel Mac。
2. 先在本机使用 Codex，确保本机已有 Codex 聊天记录。
3. 完整解压后双击「安装或更新.command」，自动检测并覆盖旧版，然后打开工作台。
   普通应用安装无需 Python 或 Codex CLI；安装器保留可写的原安装位置，首次默认安装到用户应用程序目录。
   原名「任务处理进度」的个性化设置、固定任务和窗口大小继续保留。
4. 浮窗置顶显示在屏幕右上角，显示每个聊天任务的阶段和进度。
5. 每次升级后首次启动会先移除本应用的旧辅助功能授权，再为新版重新申请并打开配置窗口。
   同一版本重启不会再次清除新授权。系统开关和身份验证由本人完成，其他应用的权限不受影响。
   如权限尚未生效，按窗口提示重新添加当前应用。系统身份验证由本人完成；个性化选择 Codex 时也有权限修复入口。

当前发布包仅作本地临时签名，未经过 Apple Developer ID 签名和公证。
如果系统提示无法验证开发者，请先确认文件来自本项目的 GitHub 发布页，再按 Apple 的官方说明操作：
https://support.apple.com/zh-cn/102445
不需要关闭系统整体安全保护。

二、常用操作
· 在浮窗上上下滚动可以翻页；四个位置满载时，下一页保留新建/进入任务入口。
· 默认单击任务方框：打开对应聊天。
· 默认双击任务方框：最小化所选的聊天窗口，保留任务和固定状态。
· 最小化外部 Codex/ChatGPT 窗口需要 macOS 辅助功能权限；内置聊天无需该权限，按提示在系统设置 → 隐私与安全 → 辅助功能中开启「ai工作台」。
· 已开启却未生效：菜单栏 →「辅助功能权限 / 修复」，删除系统中的旧同名条目，点 + 重新添加该窗口显示的应用并开启。窗口自动检测权限；仍未生效可点「重启浮窗」。
· 未授权提示只自动显示一次，可随时从菜单栏打开。公开包使用临时签名，升级后可能需重新添加一次授权。
· 右键任务方框：固定到任务栏、取消锁定或查看详情。
· 已固定的完成任务打开后改为等待中，保留位置；再次开始任务时更新进度。
· 空白方框：新建任务或进入已有任务。新建内容是聊天草稿，需在所选聊天窗口中点击发送。
· 浮窗右上减号：旋转聚拢成圆球；单击圆球恢复。点击范围已扩大；系统开启减少动态效果时简化动画。
· 拖动浮窗标题栏到屏幕任一边缘并松开，也会自动收起成圆球，停留在对应边缘；调整大小时不会触发。
· 圆球中心显示任务数，外圈参考进度最高的进行中任务；有待查看的完成任务时以完成颜色高亮（默认绿色）。
· 拖动边缘或底部手柄调整大小，大小和固定状态会记住。
· 项目筛选右侧的滑杆按钮：打开个性化设置，菜单栏和圆球右键也有入口。
· 个性化支持四宫格/条式列表，条形/圆环/分段进度，进行中/完成/背景颜色、背景透明度，以及四套预设方案。
· 单击打开、双击打开可独立勾选，也可同时开启。都开启时，单击打开聊天，双击切换窗口：已展开时最小化，未打开或已最小化时打开；只勾选单击时，双击只最小化；只勾选双击时，单击选中、双击切换。都不勾选时，单击选中、双击最小化。右键始终可打开、最小化、固定和查看详情。
· 打开位置可选「在 ai工作台内对话」或「在 Codex 中打开」，点击仅打开所选的一种。
· 内置聊天默认显示最近 10 条用户与 AI 消息，可改为 5 或 20 条；完整任务上下文仍保留。
· 内置聊天支持文本发送、流式回复、停止和草稿保存，使用本机 Codex CLI（或 Codex.app 内的 CLI）及既有登录。
· 未登录时按窗口提示登录，无法连接时可在 Codex 中继续。关闭聊天窗口后仍执行，退出工作台会停止内置任务。
· 背景透明度可连续调整，并提供不透明、半透明和透明背景选项；文字和进度保持清晰。
· 设置即时生效并自动保存；恢复默认保留固定任务和窗口大小。
· 个性化旁的圆圈问号：打开六步使用指引，对应位置会描边提示；可随时关闭。
· 菜单栏波形图标：使用指引、个性化设置、隐藏、显示、复位或退出浮窗。

三、作为个人插件安装（可选）
普通使用只需应用包，无需安装个人插件。
插件包需完整解压后运行「安装个人插件.command」，需要 Python 3 和支持插件命令的 Codex CLI。
插件和普通应用共用覆盖安装器，启动同一安装位置，避免混用缓存副本。旧安装器不会降级较新的有效版本。

四、进度与隐私
有计划时显示已完成步骤比例；无计划时用 ≈ 标记阶段估计，不表示精确工作量或剩余时间。
「已完成」表示当前一轮结束，不保证整个项目全部完成。
进度监测在本机读取 Codex 会话文件，不收集遥测。点击发送内置消息后，Codex CLI 按其配置向模型服务发送内容和任务上下文，使用相应账户额度；工作台不直接读取或上传登录凭据。未发送草稿保存在本机。
不支持 Windows/Linux；云端且未保存到本机的聊天不在监测范围。
本机 Codex 数据结构变动后，软件可能需要更新。
