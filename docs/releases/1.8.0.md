软件更名为「ai工作台」。新增个性化设置、覆盖安装和分步使用指引。

新增个性化设置：点击项目筛选右侧的滑杆按钮，即可调整浮窗外观和打开任务的方式。

- 四宫格、条式列表两种排列，每页四个任务。
- 条形、圆环、分段三种进度显示，保留百分比与阶段信息。
- 自定义进行中进度、完成提示、界面背景颜色，文字深浅自动适应背景，圆球同步配色。
- 经典四格、简洁条式、暮色圆环、清爽浅色四套预设，带实时预览。
- 保留默认单击打开、双击最小化模式；新增双击打开模式，单击只选中任务。
- 两种模式均可右键打开、最小化、固定任务和查看详情。选中或最小化不清除完成提示，成功打开聊天后才确认已查看。
- 所有个性化设置自动保存，重启后恢复；恢复默认保留固定任务和窗口大小。

- 个性化旁的圆圈问号开启六步使用指引，在实际浮窗上标记对应位置。
- 扩大右上角缩成圆球按钮的点击范围，加入旋转聚拢动效；系统开启减少动态效果时简化动画。
- 拖动浮窗到屏幕任一边缘并松开，自动缩成圆球停靠；调整大小不会触发收起。
- 已固定的完成任务打开查看后改为「等待中」，清除完成提醒并保留位置；新一轮执行后重新更新进度。
- 应用下载包新增「安装或更新.command」，与个人插件共用原生覆盖安装器。检测旧名和新版，替换旧版并保留原个性化、固定任务、已查看记录和窗口大小。

普通用户下载 `task-processing-progress-1.8.0-macos-universal.zip`；个人插件用户下载 `task-processing-progress-1.8.0-codex-plugin.zip`。支持 macOS 13 及以上、Apple 芯片和 Intel Mac。

保留 1.7.1 的权限修复功能。公开包仍采用临时签名，升级后最小化聊天窗口的辅助功能权限可能需要重新添加一次；可从菜单栏「辅助功能权限 / 修复」定位当前应用。单击或双击打开任务无需此权限。
