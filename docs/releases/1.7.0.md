「任务处理进度」首次公开发布，支持 macOS 13 及以上的 Apple 芯片和 Intel Mac。

普通用户下载 `task-processing-progress-1.7.0-macos-universal.zip`，解压后将「任务处理进度.app」拖入应用程序，再打开。

可选个人插件包：`task-processing-progress-1.7.0-codex-plugin.zip`。完整解压后运行「安装个人插件.command」；需要 Python 3 和支持插件命令的 Codex CLI。

功能包括：四格置顶浮窗、任务百分比与阶段估计、圆球模式、完成高亮、右键固定任务、等待状态、窗口缩放、单击进入聊天和双击最小化 ChatGPT/Codex 窗口。

所有聊天数据在本机读取，无遥测。双击最小化需要用户开启 macOS 辅助功能权限。发布包未经过 Apple Developer ID 签名和公证；系统可能提示无法验证开发者，详情见包内安装说明。

目前依赖本机 Codex 会话存储格式，不支持 Windows/Linux，也不监测未保存到本机的云端聊天。百分比有计划时按步骤计算，无计划时为明确标注的阶段估计。
