# 任务处理进度

macOS 原生伴随工具。双击 `dist/任务处理进度.app` 启动，浮窗默认位于屏幕右上角，置顶并跟随桌面空间。菜单栏波形图标可隐藏、显示、复位和退出。拖动浮窗空白区域可移动，右上减号可最小化为圆球，点击圆球恢复浮窗。

- 每 3 秒读取本机 Codex 非归档聊天，按具体聊天任务展示，每个正在执行的聊天任务独占一个方框，同项目多个任务分别显示；完成方框显示 100% 并保留，点击打开聊天后移除（固定任务保留）；未固定的中断和未知状态会话隐藏；可按项目筛选。
- 默认以 2×2 圆角卡片展示，每页四个位置；标题在上、进度条在下，不足四个时空位显示“新建 / 进入任务”入口，超过四个可翻页。点击卡片直接打开对应 Codex 聊天；右键“查看进度详情”打开摘要、计划步骤和估计依据。浮窗默认尺寸为 240×268，可拖动窗口边缘或底部左右两个缩放手柄调整大小，四格布局随尺寸伸缩。浮窗和“新建或进入任务”对话框分别记住尺寸，重新启动后恢复；收起再展开浮窗也恢复展开时的尺寸。卡片顶部显示 GPT 侧边栏的当前聊天名称，每 3 秒同步重命名；项目选择器和新建/已有任务对话框也使用侧边栏项目名称，底部显示当前阶段、进度条、百分比和剩余步骤。
- 固定任务按固定顺序排在前面，其余进行中任务排在已完成任务前面。未固定的完成方框只有点击打开聊天后才移除，移除记录跨重启保留；同一聊天下一轮任务仍会再次显示。启用此功能前已结束的旧会话不回填到浮窗。
- 会话包含 `update_plan` 时按已完成步骤数计算百分比，并显示剩余步骤；各步骤工作量可能不同。
- 未提供计划时，依据编辑、编译、测试或界面检查调用估计当前阶段：准备 ≈10%、实现 ≈45%、验证 ≈75%、收尾 ≈90%。这些数字是阶段位置标记，不是实际工作量完成率或剩余时间预测。再次修改可以回到实现阶段，每个新回合重新计算；运行中未识别到操作时显示准备阶段；尚未开始的任务显示等待中，不显示估计百分比。
- 卡片注明“估计”和后续阶段；详情展示依据，验证阶段也可能仍需修复和重试。
- “本轮结束”仅表示该轮请求结束。运行状态以开始、结束和中断事件为准，不因耗时操作没有新记录而移除卡片；异常退出且缺失结束事件时可能留下运行状态。
- 所有数据在本机处理，不读取登录凭据、不修改 Codex 数据、不发送网络请求。会话摘要可能包含工作内容，屏幕共享时可从菜单栏隐藏浮窗。

## 固定任务与等待状态

左键单击任务方框打开对应聊天；双击方框将 ChatGPT 的当前普通窗口最小化到 Dock，任务方框和固定状态继续保留。已完成任务的双击不清除完成提示。单双击使用互斥识别，单击会等待系统的双击判定时间，避免双击时先打开聊天。

首次使用双击最小化时，macOS 需要辅助功能权限。按照插件提示打开“系统设置 → 隐私与安全 → 辅助功能”，开启“任务处理进度”，再双击任务方框。未授权时只显示授权提示；未打开窗口或窗口已最小化时无需操作。多个 ChatGPT 窗口同时打开时，优先最小化其最近聚焦的普通窗口，其次主窗口。

右键任务方框，选择“固定到任务栏”将任务保留在浮窗；已固定任务在同一菜单中提供“取消锁定”。“已有任务”列表也提供该菜单，可将未开始或较早的任务放入浮窗。固定卡片显示图钉，按固定顺序排在前面，固定记录跨重启保存。即使超出最近 80 个任务的范围，固定任务仍会被读取；归档任务不显示。

固定任务完成并点击查看后继续保留，完成高亮会清除；取消锁定后按普通任务规则显示：进行中的任务仍显示，已查看的完成任务及未开始任务隐藏。固定任务仍遵循当前项目筛选。

尚未开始、未记录到开始事件的任务，进度位置显示“等待中”，开始后自动切换到计划进度或阶段估计。记录不可读和已中断任务分别显示异常或中断状态。

## 圆球模式

点击浮窗右上角减号，或菜单栏“切换圆球 / 浮窗”，最小化为 64×64 圆球。点击圆球展开，拖动圆球移动；右键可展开或新建/进入任务。展开时恢复之前的浮窗尺寸，圆球模式跨重启保留。

中心数字为当前筛选范围内的任务数，包含进行中、完成待查看，以及固定保留的等待/已查看完成任务。外圈优先参考进度百分比最高的进行中任务；没有进行中任务但还有待查看的完成任务时显示 100%，只有等待任务时外圈显示 0 并注明等待中；仅有已查看的固定完成任务时显示 100% 并注明已完成，不重复高亮；没有任务时显示 0。鼠标悬停可查看参考任务名称、百分比和运行/完成数量；阶段估计仍标注“≈”。

有任一完成待查看的任务时，圆球变为绿色并柔和发光，下方显示完成数量，提示持续到点击对应完成方框。仅展开圆球不会清除提示。系统启用“减少动态效果”时保留绿色高亮并停止呼吸动画。

## 构建

需要 Apple Command Line Tools。运行 `build.command`，默认构建兼容 Apple 芯片和 Intel 的通用应用。使用当前开发工具的 SDK；需要指定 SDK 时设置 `TASK_PROGRESS_SDK`。

## 数据来源和限制

读取 `${CODEX_HOME:-~/.codex}/state_5.sqlite`（SQLite 只读模式）、`.codex-global-state.json` 中的项目名称和归属关系，以及索引指定的会话 JSONL。首次读取向前定位最近的开始事件，之后增量读取追加记录；长任务不会因为开始事件超出尾部范围而被隐藏。缺失生命周期事件时仍可能显示未知状态。不会根据文字内容猜测等待审批或任务成功。

这是独立 macOS 浮窗及可选的个人本地插件，其中的浮窗使用独立 macOS 应用实现。当前本地存储结构不是稳定公共接口，Codex 升级后可能需要适配；云端或未保存到本机的聊天不在监测范围。置顶使用 macOS floating 窗口级别，部分独占全屏应用可能遮挡。

诊断：`dist/任务处理进度.app/Contents/MacOS/CodexProgress --diagnose` 输出任务数量和读取错误；`--diagnose-stages` 输出状态和阶段数据。

验证：`python3 tests/check.py`，覆盖会话过滤、事件状态、计划比例、阶段推断、返回修改、新回合重置、长会话、完成保留、点击移除和跨重启状态，以及圆球任务统计、领先任务选择、完成提示、项目筛选和窗口尺寸恢复，以及固定/取消锁定、等待状态转换、固定完成任务查看和较早任务读取。窗口最小化使用模拟窗口检查未授权时不读取或修改窗口、聚焦/主窗口优先级、已最小化窗口排除和操作失败结果。

## 个人插件

插件名称：任务处理进度；内部标识：`task-processing-progress@local-personal`。

已安装于个人插件目录。可在插件页面打开，也可在新聊天中输入“打开任务处理进度浮窗”。个人源清单位于 `~/.agents/plugins/marketplace.json`，源包位于 `~/.codex/plugins/task-processing-progress`；Codex 加载安装后的缓存副本。

`install-personal.command` 可重新构建并更新个人源目录及安装记录。修改源码后需要重新安装/刷新该插件，应用运行中不会自动载入新的二进制。

## 新建与已有任务

点击空白方框打开任务对话框。“新建任务”可选择已有项目或其他本地文件夹，并填写任务内容；“新建并打开”把内容带入 Codex 新聊天输入框，在 Codex 中点击发送后开始执行。“已有任务”可搜索最近的本地非归档聊天并直接打开，运行中的聊天优先。四格都占满时，菜单栏仍提供“新建 / 进入任务”入口。
