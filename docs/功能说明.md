# ai工作台

macOS 原生伴随工具。双击 `dist/ai工作台.app` 启动，浮窗默认位于屏幕右上角，置顶并跟随桌面空间。菜单栏波形图标可隐藏、显示、复位和退出。拖动浮窗标题栏可移动，右上减号可最小化为圆球，点击圆球恢复浮窗。

- 每 3 秒读取本机 Codex 非归档聊天，按具体聊天任务展示，每个正在执行的聊天任务独占一个方框，同项目多个任务分别显示；完成方框显示 100% 并保留，点击打开聊天后移除（固定任务保留）；未固定的中断和未知状态会话隐藏；可按项目筛选。
- 默认以 2×2 圆角卡片展示，每页四个位置；标题在上、进度条在下，不足四个时空位显示“新建 / 进入任务”入口，可用滚轮或底部箭头上下翻页；最后一页满载时，额外保留一页空白任务入口。触控板一次滑动只翻一页，惯性不会连续跳页。点击卡片打开个性化设置中所选的内置或 Codex 聊天；右键“查看进度详情”打开摘要、计划步骤和估计依据。浮窗默认尺寸为 240×268，可拖动窗口边缘或底部左右两个缩放手柄调整大小，四格布局随尺寸伸缩。浮窗和“新建或进入任务”对话框分别记住尺寸，重新启动后恢复；收起再展开浮窗也恢复展开时的尺寸。卡片顶部显示 GPT 侧边栏的当前聊天名称，每 3 秒同步重命名；项目选择器和新建/已有任务对话框也使用侧边栏项目名称，底部显示当前阶段、进度条、百分比和剩余步骤。
- 固定任务按固定顺序排在前面，其余进行中任务排在已完成任务前面。未固定的完成方框只有点击打开聊天后才移除，移除记录跨重启保留；同一聊天下一轮任务仍会再次显示。启用此功能前已结束的旧会话不回填到浮窗。
- 会话包含 `update_plan` 时按已完成步骤数计算百分比，并显示剩余步骤；各步骤工作量可能不同。
- 未提供计划时，依据编辑、编译、测试或界面检查调用估计当前阶段：准备 ≈10%、实现 ≈45%、验证 ≈75%、收尾 ≈90%。这些数字是阶段位置标记，不是实际工作量完成率或剩余时间预测。再次修改可以回到实现阶段，每个新回合重新计算；运行中未识别到操作时显示准备阶段；尚未开始的任务显示等待中，不显示估计百分比。
- 卡片注明“估计”和后续阶段；详情展示依据，验证阶段也可能仍需修复和重试。
- “本轮结束”仅表示该轮请求结束。运行状态以开始、结束和中断事件为准，不因耗时操作没有新记录而移除卡片；异常退出且缺失结束事件时可能留下运行状态。
- 进度数据在本机处理，不读取登录凭据；内置对话由 Codex CLI 执行，发送时按其配置连接模型服务并保存任务记录。会话摘要可能包含工作内容，屏幕共享时可从菜单栏隐藏浮窗。

## 固定任务与等待状态

默认左键单击任务方框打开内置聊天；双击方框最小化所选的聊天窗口，任务方框和固定状态继续保留。已完成任务的双击不清除完成提示。单双击使用互斥识别，单击会等待系统的双击判定时间，避免双击时先打开聊天。

选择 Codex 打开位置并使用双击最小化外部窗口时，macOS 需要辅助功能权限；内置窗口无需此权限。未授权时只自动打开一次修复窗口，关闭后再次双击不会反复弹出；菜单栏“辅助功能权限 / 修复”可随时打开。窗口显示实际运行应用的完整位置，每 3 秒检查权限，也可手动检测或重启浮窗。若系统开关已开启但仍未生效，删除旧同名授权条目，再添加此处显示的应用并开启。临时签名版本升级后旧授权可能失效，需要重新添加一次。个人插件统一使用覆盖安装器返回的应用位置，相同应用不重复复制或重签名，旧缓存不会降级新版。未打开聊天窗口或窗口已最小化时无需操作；窗口读取错误会显示操作失败，不再被误判成“没有窗口”。多个 ChatGPT 窗口同时打开时，优先最小化其最近聚焦的普通窗口，其次主窗口。

右键任务方框，选择“固定到任务栏”将任务保留在浮窗；已固定任务在同一菜单中提供“取消锁定”。“已有任务”列表也提供该菜单，可将未开始或较早的任务放入浮窗。固定卡片显示图钉，按固定顺序排在前面，固定记录跨重启保存。即使超出最近 80 个任务的范围，固定任务仍会被读取；归档任务不显示。

固定任务完成并点击查看后继续保留，完成高亮会清除，状态和进度显示改为等待中；下一轮开始时恢复新的执行进度。取消锁定后按普通任务规则显示：进行中的任务仍显示，已查看的完成任务及未开始任务隐藏。固定任务仍遵循当前项目筛选。

尚未开始、未记录到开始事件的任务，进度位置显示“等待中”，开始后自动切换到计划进度或阶段估计。记录不可读和已中断任务分别显示异常或中断状态。

## 个性化设置

项目选择器右侧的滑杆按钮打开个性化设置，菜单栏及圆球右键也有入口。设置窗口可调整大小并记住尺寸。

四宫格与条式列表都保留每页四个位置，空位可新建或进入任务。每个位置可选择条形、圆环或分段进度，均显示相同的百分比，等待状态不显示虚假的完成率。可自定义进行中颜色、完成提示颜色、界面背景及 0–100% 背景透明度，另有不透明、半透明、透明背景快捷按钮；圆球使用相同配色，文字根据背景自动切换深浅。

预设方案包括经典四格、简洁条式、暮色圆环、清爽浅色。方案调整排列、进度样式及颜色，但保留用户选择的点击方式。颜色与排列仍可单独调整，预览即时更新，所有设置自动保存并跨重启保留。

默认模式为单击打开聊天、双击最小化聊天窗口。单击打开与双击打开是独立复选框，可同时开启；同时开启时，两种点击都打开所选聊天，双击只触发一次。只开启双击时，单击只选中并描边提示；未开启双击打开时，双击最小化聊天窗口。两项都关闭时，单击选中并通过右键打开。选中不会清除完成提示。无论哪种组合，右键都提供打开任务聊天、最小化聊天窗口、固定/取消锁定及详情。打开失败时保留完成提示和方框；成功打开后才确认已查看。辅助功能权限仅在最小化外部聊天窗口时需要。打开位置可选内置聊天或 Codex，每次打开只使用选中的一种。内置窗口显示最近 5／10／20 条消息，默认 10 条。

恢复默认只重置个性化外观与点击方式，不影响固定任务、已查看记录、浮窗大小、对话位置或最近消息条数。

## 圆球模式

点击浮窗右上角减号，或菜单栏“切换圆球 / 浮窗”，旋转聚拢成 64×64 圆球。减号的点击范围扩大为 32×26。拖动浮窗标题栏到屏幕任一边缘并松开也会自动收起，并停靠到对应边缘；调整大小和正常右上角初始位置不会触发。系统开启减少动态效果时省略旋转。点击圆球展开，拖动圆球移动；右键可展开或新建/进入任务。展开时恢复之前的浮窗尺寸，圆球模式跨重启保留。

中心数字为当前筛选范围内的任务数，包含进行中、完成待查看，以及固定保留的等待任务。外圈优先参考进度百分比最高的进行中任务；没有进行中任务但还有待查看的完成任务时显示 100%，只有等待任务时外圈显示 0 并注明等待中；没有任务时显示 0。鼠标悬停可查看参考任务名称、百分比和运行/完成数量；阶段估计仍标注“≈”。

有任一完成待查看的任务时，圆球以完成颜色（默认绿色）柔和发光，下方显示完成数量，提示持续到点击对应完成方框。仅展开圆球不会清除提示。系统启用“减少动态效果”时保留完成高亮并停止呼吸动画。

每次升级后首次启动，先调用 macOS 自带的 tccutil，仅清除 local.codex.progress 的 Accessibility 旧授权决定；成功后由新版进程重新发起辅助功能授权申请并显示配置窗口。新授权开关和身份验证由用户在系统窗口完成。每个版本/构建只执行一次，同一版本再次启动不会再次清除新授权；清除失败会显示手动移除旧条目、重新添加当前应用的步骤。个性化选择 Codex 对话时有「辅助功能权限 / 修复」按钮。

## 覆盖安装与升级

普通应用包完整解压后运行「安装或更新.command」，不需要 Python 或 Codex CLI。应用与个人插件使用相同原生安装器，自动检测用户及系统应用程序目录中的「任务处理进度.app」和「ai工作台.app」，确认属于本软件后替换；保留可写的原安装位置，没有旧版时默认安装到用户应用程序目录。旧进程先退出，复制并校验完整应用，再替换；相同版本和文件直接复用，旧安装包不会降级较新的有效版本。

更名仍保留原应用标识 local.codex.progress 和个性化存储键，继续使用旧版设置、固定任务、完成已查看记录和窗口大小；不复制可能过时的偏好文件，不重置设置。无关的同名应用不会被覆盖。

## 使用指引

个性化旁的圆圈问号打开六步指引：任务打开、进度含义、固定与详情、新建任务、个性化设置、圆球模式。每步在实际浮窗上标记相关位置，可前后切换或随时关闭。菜单栏和圆球右键也可开启；从圆球开启时先展开，关闭指引后恢复圆球状态。

## 构建

需要 Apple Command Line Tools。运行 `build.command`，默认构建兼容 Apple 芯片和 Intel 的通用应用。使用当前开发工具的 SDK；需要指定 SDK 时设置 `TASK_PROGRESS_SDK`。

## 数据来源和限制

读取 `${CODEX_HOME:-~/.codex}/state_5.sqlite`（SQLite 只读模式）、`.codex-global-state.json` 中的项目名称和归属关系，以及索引指定的会话 JSONL。首次读取向前定位最近的开始事件，之后增量读取追加记录；长任务不会因为开始事件超出尾部范围而被隐藏。缺失生命周期事件时仍可能显示未知状态。不会根据文字内容猜测等待审批或任务成功。

这是独立 macOS 浮窗及可选的个人本地插件，其中的浮窗使用独立 macOS 应用实现。当前本地存储结构不是稳定公共接口，Codex 升级后可能需要适配；云端或未保存到本机的聊天不在监测范围。置顶使用 macOS floating 窗口级别，部分独占全屏应用可能遮挡。

诊断：`dist/ai工作台.app/Contents/MacOS/CodexProgress --diagnose` 输出任务数量和读取错误；`--diagnose-stages` 输出状态和阶段数据。

验证：`python3 tests/check.py`，覆盖会话过滤、事件状态、计划比例、阶段推断、返回修改、新回合重置、长会话、完成保留、点击移除和跨重启状态，以及圆球任务统计、领先任务选择、完成提示、项目筛选和窗口尺寸恢复，以及固定/取消锁定、等待状态转换、固定完成任务查看和较早任务读取。个性化检查覆盖配色与布局保存、方案保留点击方式、四种点击组合及旧设置迁移、完成提示与固定任务保留、重置和异常设置恢复。窗口最小化使用模拟窗口检查未授权时不读取或修改窗口、聚焦/主窗口优先级、已最小化窗口排除和操作失败结果。

## 个人插件

插件名称：ai工作台；内部标识：`task-processing-progress@local-personal`。

已安装于个人插件目录。可在插件页面打开，也可在新聊天中输入“打开ai工作台浮窗”。个人源清单位于 `~/.agents/plugins/marketplace.json`，源包位于 `~/.codex/plugins/task-processing-progress`；Codex 加载安装后的缓存副本。

`install-personal.command` 可重新构建并更新个人源目录及安装记录。修改源码后需要重新安装/刷新该插件，应用运行中不会自动载入新的二进制。

## 新建与已有任务

点击空白方框打开任务对话框。“新建任务”可选择已有项目或其他本地文件夹，并填写任务内容；“新建并打开”把内容带入所选位置的聊天输入框，点击发送后开始执行。“已有任务”可搜索最近的本地非归档聊天并直接打开，运行中的聊天优先。四格都占满时，菜单栏仍提供“新建 / 进入任务”入口。

## 内置对话

使用本机 Codex CLI（含 Codex.app 内的 CLI）的私有 stdio app-server 连接，不开放网络监听端口。通过 Codex 现有登录发送文本、接收流式回复，关闭聊天窗口后继续运行；退出工作台时如有内置任务执行会询问是否停止并退出。最近消息只包含用户与 AI 消息；完整上下文由 Codex 保留。未发送草稿与消息显示条数保存在本机。

Codex 中正在执行的任务先只读查看，结束后可续聊。命令、文件修改审批和用户问题由确认卡片处理，不自动批准；不支持的交互提示在 Codex 中继续。连接断开或发送超时不自动重发，手动刷新确认后才能再次发送。发送会使用模型服务和账户额度，遵循 Codex 的本机配置；工作台不直接读取登录凭据或提供云同步。

可调整聊天窗口大小，默认 420×520、最小 360×380，尺寸跨重启保存。项目选择对应本地工作目录；未指定项目时使用 Codex 数据目录内的 ai-workbench-tasks 文件夹。内置聊天不需要辅助功能权限。

验证：`python3 tests/check_chat.py` 使用隔离的协议模拟服务，覆盖分片 UTF-8、历史消息数量、流式回复、停止、完成与启动应答乱序、审批、问题、草稿、运行中禁止并行发送、新建目录和断线恢复，不提交真实用户任务。
